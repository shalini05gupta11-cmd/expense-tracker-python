# Expense Tracker (Python)

A simple console-based Expense Tracker built using Python.  
This project allows users to add expenses, view saved expenses, and calculate total spending using file input-output.

## Features
- Add daily expenses
- View all saved expenses
- Calculate total expense
- Data stored using file input-output

## Technologies Used
- Python
- File Handling (File I/O)

## How to Run
1. Make sure Python is installed
2. Download the file `expense_tracker_easy.py`
3. Run the program using:
   ```bash
   python expense_tracker_easy.py
